# AGENTS.md

## Project overview
PWSEditor is a Java Swing desktop application for editing Part-Whole Statecharts (PWS). The project uses plain `javac` builds (no Maven/Gradle) and ships bundled third-party JARs in `lib/`.

## Build and run
- Build classes: `./scripts/build.sh`
- Run from classes: `java -cp "out:lib/*" pws.editor.PWSEditor`
- Build runnable jar: `./scripts/build-jar.sh` (outputs `dist/PWSEditor.jar`)
- Run jar: `java -jar dist/PWSEditor.jar`
- Build macOS app bundle: `./scripts/build-macos-app.sh`
- Generate Javadoc: `./scripts/generate-javadoc.sh`

## Repository layout
- `src/` Java sources (packages: `assembly`, `editor`, `machinery`, `pws`, `serializer`, `smalgebra`, `utility`, `tutorial`)
- `lib/` third-party JARs used for build and runtime
- `scripts/` build helpers
- `docs/` documentation (includes generated Javadoc)
- `dist/` build artifacts (jar/app bundle)
- `out/` compiled classes

## Coding conventions
- Follow existing formatting (4-space indentation, minimal reformatting).
- Keep Swing UI changes on the EDT (use `SwingUtilities.invokeLater` when updating UI from background work).
- Prefer small, localized changes; avoid broad refactors without explicit request.
- When adding dependencies, place JARs in `lib/` and update the build scripts accordingly.

## Testing
- There are no automated tests in this repo.
- For manual smoke checks, build and launch the app, then open `test_pws.pws` to verify basic file open/edit flows.

## Generated files
Do not edit build outputs directly: `out/`, `dist/`, and `docs/javadoc` are generated by scripts.
